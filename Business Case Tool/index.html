Smart Industry – Innovation Business Case Tool

Duration: ~3 months

ASP.NET Core Blazor Server · Clean Architecture · Event-Driven System Lead Developer / Full-Stack Engineer (Solo Delivery)

Context

Smart Industry, a Dutch innovation think tank and consultancy organization, required a digital platform to support coaches working with SME clients in the manufacturing sector. The goal was to replace spreadsheet-based workflows with a structured application for building, evaluating, and tracking innovation investment business cases.

The system is used during coaching sessions where coaches and clients collaboratively define and assess innovation scenarios, investment decisions, and expected outcomes.

Problem

  • Business case development was fragmented across spreadsheets and documents
  • No centralized system for tracking or reusing client cases
  • Lack of structured guidance in innovation decision-making
  • No real-time collaboration between coach and client during sessions

Solution

I designed and implemented a full-stack web application from scratch, including architecture, domain modeling, and deployment. The system was built using a clean/hexagonal architecture with event-driven communication enabling real-time interaction between users.

  • ASP.NET Core Blazor Server application with SQL Lite persistence
  • Auth0-based authentication and role separation (coach/client)
  • Azure-based email workflows for notifications and session coordination
  • Real-time updates enabling live collaboration during coaching sessions

Domain-Driven Workflow

The core workflow was co-designed with domain experts from TNO to ensure alignment with real-world innovation investment practices in the manufacturing sector.

  • Guided step-by-step business case structuring
  • Structured capture of assumptions, costs, and expected outcomes
  • Standardized evaluation of innovation investment scenarios

Key Features

Real-time collaboration
Coaches and clients work on shared business cases with instant updates across sessions.

Scenario analysis
Users can modify assumptions and immediately compare alternative investment outcomes.

Export system
Business cases can be exported as structured dashboards for reporting and decision-making.

Impact

  • Replaced fragmented spreadsheet workflows with a centralized decision-support tool
  • Enabled structured, repeatable innovation coaching sessions
  • Improved traceability and consistency in business case development
  • Allowed real-time collaborative evaluation between coaches and clients

Technical Highlights

  • Clean / Hexagonal architecture separating domain logic from infrastructure
  • Event-driven system enabling live UI synchronization
  • Domain-specific calculation models implemented in C#
  • Scalable modular workflow designed for extension to new industries
